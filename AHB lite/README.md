This project implements a simple AHB-Lite Master and Slave in Verilog, with both modules combined in a single design file and a separate testbench for verification. The Master converts basic write/read requests into the standard two-phase AHB-Lite protocol (address phase followed by data phase) using HADDR, HWRITE, HTRANS, HWDATA, and HRDATA, while the Slave implements a 16x32-bit memory-mapped register file with zero wait-state response (HREADY tied high). The design was verified in simulation using Icarus Verilog, correctly performing back-to-back writes and read-backs with matching data at each address. This confirms correct address-to-data phase timing and protocol compliance for a non-pipelined, single-transfer AHB-Lite interface.
