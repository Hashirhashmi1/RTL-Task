This project implements a complete AXI4-Lite Master-Slave interface in Verilog, with the Master and Slave as independent, reusable modules and a separate testbench for verification. The Master converts simple write/read requests into the full 5-channel AXI4-Lite handshake (write address, write data, write response, read address, read data), while the Slave implements a 16x32-bit memory-mapped register file that responds to those transactions. The design was verified in simulation (Icarus Verilog and Xilinx Vivado), successfully performing back-to-back writes and read-backs with correct data and OKAY responses on every transaction. This confirms correct handshake timing and protocol compliance for single-beat, non-burst AXI4-Lite transfers.
